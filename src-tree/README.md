# AutoSZUWeb 1.7.0-szu

深圳大学校园网菜单栏认证工具，当前本地维护与验证目标为 macOS 14 及以上、Apple Silicon arm64。

## 当前实现

- 原生菜单栏、账号与监测设置、故障记录及只读网络诊断。
- 物理校园门户识别、SRun 会话状态、可信认证拦截与未知故障复查。
- 可取消认证流程、进程间认证协调、认证后外网验证。
- 自适应监测、快速完成的并发探测、按需网速采样。
- AES-GCM 本地凭据、受限文件权限、原子设置合并与卸载协调。
- 隐藏密码输入和标准输入认证入口。

## 本机构建与测试

从包含固定依赖的工作区根目录执行。

```bash
cd ..
./test.sh
./build.sh
```

产物为 `build/AutoSZUWeb.app`。依赖清单位于 `deps/manifest.json`，构建及回归使用同一套运行库。

使用说明、认证策略、数据位置、退出码、验证范围及回退说明见 [工作区说明](../README.md)。历史版本文档保留于 `docs/`。
